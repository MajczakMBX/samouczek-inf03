1. Podstawy działania CSS

Sposoby dołączania stylów

  • Zewnętrzny plik (Zalecany): Arkusz stylów w osobnym pliku, podłączony w <head> znacznikiem <link rel="stylesheet" href="style.css">Standard na egzaminie INF.03.
  • Wewnętrzny arkusz: Style w sekcji <head> pomiędzy znacznikami <style> ... </style>.
  • Styl liniowy: Dopisany do elementu za pomocą atrybutu style=""Używany w ostateczności.

Kaskadowość i Dziedziczenie

  • Kaskadowość: Określa, który styl wygra przy konflikcie reguł. Hierarchia ważności (od najsłabszego): Domyślne style przeglądarki → Arkusz zewnętrzny/wewnętrzny → Style liniowe → !important. Przy równej wadze wygrywa zapis podany najpóźniej w kodzie.
  • Dziedziczenie: Przekazywanie cech z rodzica na dzieci. Dziedziczone są m.in. właściwości tekstowecolor
    font-family    NIE są dziedziczone: marginesy, obramowania, tła.

2. Selektory i Pseudoklasy

Wybieranie elementów (Proste)

  • Znacznika: Zapisywany nazwą tagup
    h1
  • Klasy: Zapisywany z kropką.przyciskMożna używać wielokrotnie.
  • Identyfikatora: Zapisywany z hashem#naglowek-glownyUnikalny, tylko raz na stronie.
  • Uniwersalny: Gwiazdka*Wybiera wszystkie elementy.

Selektory relacji: Potomek i Dziecko

  • Potomek: (Spacja np. A B) Wybiera wszystkie elementy B wewnątrz ANiezależnie od głębokości zagnieżdżenia (dzieci, wnuki itd.).
  • Dziecko: (Znak > np. A > B) Wybiera tylko bezpośrednie dzieci elementu A(Jeden poziom niżej).

Pseudoklasy: :hover
:nth-child()

  • :hoverStylizuje element, gdy najedzie na niego kursor myszy.
  • :nth-child(n)Wybiera element po jego kolejności w grupie.

4. Model Pudełkowy i Wyświetlanie

Właściwość display (Typy elementów)

  • Blokowe:blockZaczynają się od nowej linii, zajmują całą dostępną szerokość. Można im nadawać `width` i marginesy<div>
    <p>
  • Liniowe:inlineUkładają się w tekście, zajmują tylko tyle miejsca co zawartość. Ignorują `width` i górne/dolne marginesy<span>
    <a>
  • Liniowo-blokowe:inline-blockStoją w linii obok siebie, ale reagują na nadawanie wymiarów i marginesów.

Box Model:

  • width/heightSzerokość i wysokość zawartości.
  • paddingDopełnienie wewnątrz (między tekstem a ramką).
  • borderRamka wokół elementu1px solid black
  • marginMargines na zewnątrz (odstęp od innych bloków).

Ważne (box-sizing): Domyślnie padding i border powiększają szerokość elementu. Użycie box-sizing: border-box; sprawia, że są one wliczane do środka, a całkowita szerokość `width` pozostaje stała.

5. Układy Stron (Layout) i Pozycjonowanie

Opływanie: float

  • Działanie: Wyrywa element z normalnego przepływu i spycha do krawędzileft
    right    Tekst oblewa go z drugiej strony.
  • Czyszczenie (Clear): Aby uniknąć rozpadu układu, na elemencie poniżej używa się clear: both;

Pozycjonowanie: position

  • staticDomyślne, właściwości top/left nie działają.
  • relativePrzesuwa element względem jego własnego, pierwotnego miejsca (zostawia tam pustą lukę).
  • absoluteWyjęty z układu, pozycjonowany względem najbliższego rodzica z position: relative.
  • fixedPrzyklejony na stałe do okna przeglądarki (nie znika przy przewijaniu).
  • stickyZachowuje się normalnie, ale przy przewijaniu przykleja się do wyznaczonej krawędzi (np. top: 0).

Układ Elastyczny: Flexbox

  • Do czego służy: Jednowymiarowy układ w rzędzie lub kolumnie. Idealny do centrowania i nawigacji. Nadawany rodzicowi.
  • Kluczowe właściwości:
    • display: flex;Aktywuje układ.
    • flex-direction: row / column;Kierunek.
    • justify-contentWyrównanie w osi głównejcenter
      space-between
    • align-itemsWyrównanie w osi pomocniczejcenter w pionie

Układ Siatki: CSS Grid

  • Do czego służy: Dwuwymiarowa siatka dla całych stron (kolumny i wiersze jednocześnie).
  • Kluczowe właściwości: display: grid; oraz podział za pomocą grid-template-columns: 200px 1fr 1fr; (np. menu 200px i reszta na pół).

    Odstępy ustawia się właściwością gap

7. Responsywność strony (RWD)

Jak tworzyć Responsive Web Design

  • Viewport: Dodaj w HTML. <meta name="viewport" content="width=device-width, initial-scale=1.0">
  • Elastyczność: Zamiast sztywnych wymiarów (px), używaj procentówwidth: 100%
    max-width: 1200px
  • Media Queries: Reguły wyłapujące wielkość ekranu, wstawiane na końcu pliku CSS.
.kolumna { width: 100%; }

@media screen and (min-width: 768px) {
    .kolumna { width: 50%; float: left; }
}

8. Animacje i Przejścia

Płynne przejścia: transition

Dodawane do podstawowego elementu (nie do :hover), aby zmiana była płynna w obie strony.

.przycisk {
    background-color: blue;
    transition: background-color 0.3s ease; /* Co, ile czasu, jak płynnie */
}
.przycisk:hover { background-color: red; }

Złożone animacje: animation
@keyframes

Pozwalają na wieloetapowe animacje działające automatycznie.

@keyframes ruch {
    0% { transform: translateX(0); }
    100% { transform: translateX(100px); }
}

.element {
    animation: ruch 2s linear infinite;
}
